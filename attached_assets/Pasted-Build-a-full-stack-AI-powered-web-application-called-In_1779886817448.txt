Build a full-stack AI-powered web application called “Intelligent Data Dictionary Agent” using React.js for the frontend and Node.js + Express for the backend. The application should allow users to upload CSV files, automatically analyze dataset structure, infer metadata, identify relationships, and generate human-readable data dictionary descriptions using the Gemini API.

The UI should look modern, premium, responsive, minimal, and futuristic with a black background and the following color palette:

- Cyan: #6ccff6
- Black: #001011
- Gray: #757780
- White: #fffffc
- Lime: #98ce00

Use Tailwind CSS for styling.

========================================
PROJECT GOAL
========================================

The system should:
1. Upload CSV datasets
2. Parse and analyze the dataset
3. Detect:
   - column names
   - data types
   - null values
   - unique values
   - relationships
   - primary key candidates
   - categorical fields
   - numeric fields
   - date fields
4. Use Gemini API to generate:
   - human-readable column descriptions
   - dataset summary
   - business meaning
   - relationship explanations
5. Generate a professional Data Dictionary table
6. Provide export functionality
7. Visualize schema relationships
8. Support multiple uploaded datasets in the future
